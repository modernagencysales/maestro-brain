## Durable resources

S03-T03 does not add durable tables or migrations. It consumes the S02 stable
Brain page, editor document, and revision-fence contracts from the web feature
adapter and reusable editor surface.

## Lifecycle behavior

The Brain workspace preserves lifecycle and revision fences at the browser seam:
edit sessions keep the selected `expectedCurrentRevisionKey`, public snapshot
commits send that fence with the live editor document, and stale or
lifecycle-revoked failures surface as workspace conflict state instead of
silently overwriting the current page. Viewers mount read-only editor state, and
cross-Brain or unauthorized URL keys resolve through typed not-found/forbidden
states without leaking tenant existence.

## Compatibility and rollback

Rollback can route the Brain page to a read-only maintenance surface while
leaving persisted S02 page and revision data unchanged. No destructive reverse
migration is required.
