## Implemented export and artifact contract

- `packages/template-core/src/brainExport.ts` produces a deterministic
  `maestro-brain-export/v1` bundle with stable paths and ordering, canonical
  JSON, per-file SHA-256 hashes, a manifest, byte counts, and lifecycle/policy
  generations.
- `packages/template-core/src/brainExportJob.ts` records idempotency and a
  lifecycle-generation fence. A stale generation revokes the job before
  encoding; a ready job records manifest/artifact hashes, size, and file count.
- `packages/template-core/src/brainExportStorage.ts` implements the local
  artifact-store contract: immutable byte copies, expiry, lifecycle revocation,
  purge, and fail-closed reads after expiry, revocation, or purge.
- `packages/convex/confect/tables/brainExportJobs.ts` and
  `packages/convex/convex/brain/exports.ts` add durable, idempotent Convex job
  metadata, scheduled worker execution, native temporary object storage,
  lifecycle/policy-fenced publish/download, and byte deletion on expiry,
  revocation, purge, and failed publication.

The local Convex harness now proves the request-to-storage lifecycle and
fail-closed fences. Hosted deployment, provider smokes, and pilot evidence are
still external release gates.

## Lifecycle, compatibility, and rollback

The local contract is additive and export-only. It does not add import or Git
sync. Artifact reads require the current lifecycle generation and an unexpired,
unrevoked, unpurged artifact. A generation change is a local rollback fence; it
is not a hosted deployment rollback rehearsal.
