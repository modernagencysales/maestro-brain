# S05-T01 Source Ledger Lifecycle Adoption

S05-T01 adds the source-ledger schema envelope only. Captured source rows use
stable tenant keys, schemaVersion `1`, and the lifecycle states
`active -> deleted_tombstone -> redacted -> purged` with purge fences on
content-bearing tables.

The lane-owned migration fragments attest that S05 is `new_tables_only`; the
canonical migration registry remains integration-owned and was not edited by
this product lane.
